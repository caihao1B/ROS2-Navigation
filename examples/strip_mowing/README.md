# 割草：关刀换向与有效作业面积

阿克曼车在地头按有向路径改变前进或倒车方向。切换挡位前，底盘和刀具都应停稳。条带上的有效作业通过刀具反馈和作业边界计算，车辆经过的整段路线不直接折算成割草面积。

```bash
python3 examples/strip_mowing/run.py
```

运行使用 NumPy 与 Shapely。程序从两次独立 Gazebo 场景读取实际记录，分别输出关刀换向的逐段结果和开刀作业的面积。

| 文件 | 作用 |
| --- | --- |
| `parking-observations.json.gz` | 含冻结路径几何、原停车和航向门限、方向切换事件，以及底盘、刀具和独立物理位姿的实测序列。评估器核对车身轨迹、每一挡的实际行驶方向、末端窗的停稳、定位误差和刀具关闭。 |
| `cutting-observations.json.gz` | 来自另一场入口作业。目标多边形、仿真侧刀具扫掠多边形和账本记录的 WKB 几何分别提供参考边界、实际切过的面积和反馈确认面积。并集运算可避免重复计量。 |
| `reference.json` | 存放两次场景各自的对照输出，单位为米、弧度或平方米。 |

几何记录由原任务选取的条带与地头计划导出，此入口使用随仓冻结路径。轨迹评估读取的仿真物理位姿仅用于事后独立对照。查看 [Nav2 有向曲率控制器](../../src/field_work/src/directed_path_controller.cpp) 和 [停车与面积评估](../../src/field_work/field_work/mowing_feedback.py)。
